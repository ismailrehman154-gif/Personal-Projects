# Khairway Website

Static one-page Khairway website.

## Project files

- `index.html` — site content and direct WhatsApp community links
- `styles.css` — responsive styling, Madinah gallery sizing, and NYC video carousel styles
- `script.js` — mobile navigation, dismissible group-chat dropdown, looping NYC video carousel, back-to-top, and dynamic copyright year
- `images/` — Khairway logos, Madinah photographs, and the subtle sports-pattern hero artwork
- `videos/` — NYC community clips

## WhatsApp community links

The header dropdown and community section are wired directly to the supplied Main Community, Khair Benefits, Khair Clips, Khair Insights, Khair Alerts, Khair Nikah, Khair Daily, and Khair Deeds destinations.

## QR code

Replace the `.qr-placeholder` element in `index.html` with the final QR code image when available.

## Deployment

Upload the contents of this folder to your static host (Netlify, Vercel, GitHub Pages, or another web host). `index.html` is the only HTML page required.
